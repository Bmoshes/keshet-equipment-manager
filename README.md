# ניהול ציוד — קשת פיננסים

MVP פנימי לניהול מלאי והשאלת ציוד משרדי, בנוי עם Next.js, TypeScript ו־Tailwind CSS. המערכת פועלת בעברית וב־RTL והנתונים נשמרים בזיכרון בלבד. מצב המנהל מאפשר גם להוסיף פריטי ציוד חדשים ולנהל את זמינותם.

## הפעלה

```bash
npm install
npm run dev
```

פתחו `http://localhost:3000`. מתג התפקידים בכותרת מאפשר לעבור בין סביבת עובד לסביבת מנהל.

## בדיקות איכות

```bash
npm run lint
npm run build
```

החלטות המוצר ומודל המצבים מתועדים ב־[SPEC.md](./SPEC.md), והיקף המימוש ב־[NOTES.md](./NOTES.md).
